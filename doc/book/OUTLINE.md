# 全书大纲（写作契约）

> 本文是《eBPF 从入门到精通》的**权威大纲**（v3，已经用户确认）。
> 写作过程以此为准绳：每动笔一章先对照本文，写完自查是否覆盖全部
> 小节。修改本文视同修改需求，需经确认后进行。
> 进度勾选见 [README.md](README.md)。

## 写作铁律（必须遵守）

1. **学习旅程式组织**：每章 = 动机（要解决什么）→ 历史（怎么来的）
   → 动手做 → 原理拆解 → 常见坑 → 小结与练习。机制在"需要它的
   时刻"引入（just-in-time），不搞机制穷举的专题章；
2. **内容必须详实**：每章 300 行以上，小节落到代码/报错原文/逐步
   推演层面，禁止标题党式一笔带过；
3. **一切原理配图**：流程、结构、状态演变必须配 ASCII 图（流程图/
   结构图/时间线/表格推演）；
4. **速查内容退附录**：正文不堆参数表/版本矩阵，全部进附录 A-G；
5. **每章收尾**：小结 + 动手练习；
6. 版本口径 = 内核主线版本号（backport 提醒统一指向第 15 章/附录 E）；
   Go API 以 cilium/ebpf v0.22.0 实测为准。

## 目录结构

```
第一篇 走进 eBPF ──── 认知 + 第一个程序 + 验证器

第六篇 实战 ──────── ruport-go：架构设计到逐模块精读
```
